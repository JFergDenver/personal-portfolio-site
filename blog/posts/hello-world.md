I've finally added a blog to this site. Nothing fancy — no CMS, no build
step, no database. Just Markdown files in the repo, rendered client-side.

## Why Markdown

The rest of this site is plain HTML, CSS, and JS on purpose — no
unnecessary frameworks, no bloat. The blog follows the same rule: each
post is a `.md` file under `blog/posts/`, and a small script converts it
to HTML in the browser. Writing a new post means adding a file and a
manifest entry, then committing.

## What's here so far

- Short write-ups on things I'm building
- Notes on projects as they evolve
- The occasional rabbit hole
